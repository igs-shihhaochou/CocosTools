## 二、啟動流程（InitScene → 進入遊戲）— 詳細說明

### GameInit 是什麼？

`GameInit` 是整個遊戲的啟動入口（掛在 InitScene 場景中），繼承自 `Component`。
它在 `onLoad()` 中呼叫 `Init()` 開始一連串非同步初始化步驟，直到遊戲完全就緒。

### 全域設定（檔案最上方）

```typescript
macro.ENABLE_MULTI_TOUCH = false;    // 禁用多點觸控
game.frameRate = 60;                  // 鎖定 60fps
assetManager.downloader.maxConcurrency = 12;      // 最大並行下載數
assetManager.downloader.maxRequestsPerFrame = 12; // 每幀最大請求數
```

### onLoad() — 程式進入點

```
GameInit.onLoad()
├─ sys.localStorage.setItem('gameStartTime') → 記錄啟動時間（效能監控）
├─ SetLoginExtraData()    → 收集瀏覽器/OS 資訊用於登入
├─ Init()                 → 主初始化流程（async，下方詳述）
├─ director.addPersistRootNode(this.node) → 場景切換時不銷毀此節點
└─ addTouchListener()     → 監聽父視窗觸控事件（iframe 環境）
```

### Init() 主流程 — 完整步驟解說

以下每個步驟都透過 `ProcessingLevel()` 方法執行，該方法：
- 同步模式（`async=false`）：直接執行並 resolve
- 非同步模式（`async=true`）：等待 `onComplete` callback 被呼叫才 resolve

#### 階段 1：環境準備（同步）

| 步驟 | 說明 |
|------|------|
| **CommonLib 等待** | Launcher 模式下，等待共用函式庫並行載入完成（window.__commonLibReady） |
| **BQLogger 初始化** | 初始化埋點系統，記錄版本號，發送 `loadEngine` 埋點 |
| **INTERNAL_MODE_DEBUG_SETTING** | 檢查 URL 是否帶 `InternalMode=1`，是則開啟 console |
| **CHECK_ENVIRONMENT** | 判斷平台環境：<br>• `ssoKey` 存在 → Macross 平台<br>• `logo=playgd` → SS 平台<br>• `logo=dara/Joya` → Dara 平台 |
| **GET_URL_PARAMETER** | 解析 URL 所有參數並寫入 PlatformData：<br>• `game` → 遊戲名稱<br>• `lang` → 語系<br>• `currency` → 幣種<br>• `token` → 驗證 Token<br>• `mid` → 商戶 ID<br>• `uid` → 使用者 ID<br>• `isMute` → 是否靜音<br>• `fsBtn` → 全螢幕支援<br>• `certArea/certId` → 送審資訊<br>• 版號從 URL 路徑倒數第3段取得 |
| **INIT_EVENT_MANAGER** | EventManager 單例初始化，註冊全域事件名稱 |
| **GET_CONFIG** | 取得 GameConfig（CDN 路徑等）、CurrencyConfig（幣種設定）、BundleConfig |

#### 階段 2：並行下載（Promise.all）

這些任務同時進行，全部完成才繼續：

| 步驟 | 說明 |
|------|------|
| **GetAgentInfo()** | （僅 Macross 環境）呼叫平台 API 取得代理資訊（gameId, userId, currency） |
| **GET_COMMON_SETTING** | 下載 CommonSetting.json（取得 DomainList、ClickLogSite、版本資訊） |
| **GET_PLUGIN** | 下載遠端 Plugin JS 列表（PluginPathList.json），遞迴載入每個 .js 檔案 |
| **GET_BUNDLE_VERSION** | 下載 BundleVersion.json（所有 Bundle 的版本號對照表） |
| **GAME_SETTING** | 同時下載 3 個設定檔：<br>• `GameBundleSetting.json` → 遊戲依賴的 Bundle<br>• `GameCommonBundleSetting.json` → 共用 Bundle（MessageBox、LoadingScreen）<br>• `GameSetting.json` → 遊戲設定（GameID、DefaultLang、DebugMode 等） |
| **createGA()** | Google Analytics 初始化（僅 acewin logo） |

#### 階段 3：資料設定（同步）

| 步驟 | 說明 |
|------|------|
| **TRACK_URL** | 站台回追（記錄 referrer 來源網址） |
| **MERGE_BUNDLE_CONFIG_TO_VERSION** | 將遊戲的 BundleConfig 合併到 BundleVersion（處理依賴） |
| **DEBUG_MODE_SETTING** | 根據 GameSetting.DebugMode 決定是否開啟 console |
| **COMMON_GAME_DATA** | 設定 PlatformData 核心資料：<br>• gameID、gameName<br>• lang（語系）<br>• 幣種設定（Name、Sign、Ratio、Decimal）<br>• 行動裝置判斷<br>• themeID、背景執行設定 |
| **COMMON_PLATFORM_DATA** | 根據平台（Macross/SS/Dara）設定客製化參數：<br>• SS 平台：關閉 JP/跑馬燈/驗證<br>• Dara 平台：關閉 JP/使用 sso-login.api<br>• Macross 平台：全功能開啟 |
| **SET_COMMON_LIB** | 設定 FullScreen 插件的螢幕方向 |
| **BACKGROUND_UPDATE_SETTING** | 背景執行設定（頁面不可見時是否暫停） |
| **GET_BUNDLE_CONFIG_FROM_VERSION** | 從 BundleVersion 中提取遊戲需要的 Bundle 清單 |
| **INIT_MANAGER** | 初始化各 Manager：<br>• DebugManager<br>• TopViewManager<br>• InputManager（觸控/鍵盤）<br>• SoundManager（音效）<br>• OrientationManager（螢幕方向） |

#### 階段 4：Bundle 載入（非同步，有順序）

| 步驟 | 說明 |

#### 階段 5：網路連線（非同步）

| 步驟 | 說明 |
|------|------|
| **INIT_GAME_CLIENT** | 完整的網路初始化流程：<br>1. `getServiceDomains()` → 向平台取得 Server domain 清單<br>2. **SSO Login**（Macross 環境）：<br>   • `MacrossClient.ssoLogin()` → SSO 認證<br>   • 失敗時重試機制（getSSOKeyWithRetry）<br>   • 成功後設定 PlatformData（uID, token, currency, 送審設定等）<br>3. `GameClient.init()` → 初始化 WebSocket 客戶端<br>4. `GameClient.initArkClient(gameServer)` → 建立 Ark 連線<br>5. 設定 BQLogger（arkID, arkToken）<br>6. #### 階段 7：完成

```
OnGameInitComplete()
├─ SetMultiLangDictionary()   → 從所有已載入 Bundle 中收集多語系文字
├─ EventLog.SendGameFlow()    → 送出初始化完成的 EventLog
└─ StartGame(GAME_INIT_READY) → 觸發遊戲開始
```

### StartGame 雙條件觸發機制

```typescript
readyState = GAME_CLIENT_READY | GAME_INIT_READY
// 兩個 bit 都 set 時 = ALL_READY

// 觸發：
EventManager.dispatchEvent(GAME_INIT_COMPLETE)
// → MachineHost 收到後開始主遊戲流程
```

**為什麼要兩個條件？**
因為「網路連線」和「資源載入」是並行的，誰先完成不一定。兩者都 ready 才能進入遊戲。

### 錯誤處理

- SSO Login 失敗 → 顯示 MessageBox → 關閉遊戲
- Bundle 載入失敗 → BQLogger 記錄 → 顯示錯誤
- 版本不一致 → 強制跳轉新版本 URL

## 三、主遊戲 Spin 循環（MainGameHost 狀態機）

### 狀態機設計

使用 **Queue-based FSM**（佇列狀態機），狀態依序執行：

```
[1] ReadyToSpin → [2] Spin → [3] WaitForCallback → [4] WaitForWheelStop
    → [5] WheelsAllStopped → [6] ShowAward → [7] AfterShowAward
    → [8] ProcessFinish → 回到 [1]
```

### 詳細流程圖

```
┌─────────────────────────────────────────────────────────────────┐
│  [1] ReadyToSpin                                                 │
│  ├─ 解鎖 UI，等待玩家操作                                          │
│  └─ SlotGDK.eventReadyToSpin.notify()                            │
└────────────────────────────┬────────────────────────────────────┘
                             │ 玩家點擊 Spin 按鈕
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│  [2] Spin                                                        │
│  ├─ MachineHost.sendSpin() → CmdSender → Server                 │
│  ├─ wheelsManager.spin()   → 轉輪開始旋轉動畫                      │
│  └─ awardController.reset() → 清除上次報獎                         │
└────────────────────────────┬────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│  [3] WaitForSpinRequestCallBack                                  │
│  └─ 等待 Server 回傳 spinData                                     │
│     └─ MainGameHost.setSpinData(data)                            │
│        ├─ SpinResultExArgs.parse(data) → 解析結果                  │
│        ├─ wheelsManager.spinRequestToAllBlock() → 設定停輪資料      │
│        ├─ specialGameAgent.setRequest() → 設定 FreeGame 狀態       │
│        └─ awardController.init() → 初始化報獎資訊                   │
└────────────────────────────┬────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│  [4] WaitForWheelStop                                            │
│  ├─ 轉輪持續旋轉中...                                              │
│  ├─ 快停判斷（fastSpin → quickStop）                               │
│  └─ 等待 wheelsManager.eventFinished 觸發                         │
└────────────────────────────┬────────────────────────────────────┘
                             │ 所有轉輪停止
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│  [5] WheelsAllStopped                                            │
│  ├─ SlotGDK.eventWheelStop.notify()                              │
│  └─ Feature 系統啟動（S202_Combo → Drop 消除連鎖）                  │
└────────────────────────────┬────────────────────────────────────┘
                             │ Feature 完成
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│  [6] ShowAward                                                   │
│  ├─ eventCheckMaxWin → 檢查贏分上限                                │
│  ├─ awardController.doStart() → 啟動報獎                          │
│  │  ├─ NormalWin → 短暫顯示                                       │
│  │  ├─ BigWin/MegaWin/SuperWin → 大獎宣告動畫                     │
│  │  └─ BingoAlarm → 中獎鈴聲                                      │
│  └─ finishEvent → 報獎結束                                        │
└────────────────────────────┬────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│  [7] AfterShowAward                                              │
│  ├─ 檢查是否要進入 FreeGame                                        │
│  │  ├─ 有 SG → 進入 SpecialGame 流程                              │
│  │  └─ 無 SG → 回到主循環                                         │
│  └─ wheelsManager.setPlayMode(Normal)                            │
└────────────────────────────┬────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│  [8] ProcessFinish                                               │
│  ├─ 送審延遲檢查（readyToSpinDelay）                               │
│  ├─ SlotGDK.eventProcessFinish.notify()                          │
│  ├─ setMainGameProcessQueue() → 重新排入 [1,2,3,...,8]            │
│  └─ nextProcess() → 回到 [1] ReadyToSpin                         │
└─────────────────────────────────────────────────────────────────┘
```

## 四、AltarRiches 停輪後 Feature 流程（Combo 消除）

停輪後，WheelBlockController 觸發 Feature 系統：

```
WheelBlockController.eventFinished
│
├─ FeatureController 檢查 featureList
│  └─ 找到 S202_Combo（type: End）
│
└─ S202_Combo.startFeature()
   │
   ├─ CheckMaxWin()           → 檢查並截斷 combo 陣列
   │
   └─ Drop.comboFeature(comboInfoAry)
      │
      ├─ 遍歷每個 ComboInfo：
      │  │
      │  ├─ [Combo 0] 第一手（原始盤面）→ 記錄為 lastComboInfo
      │  │
      │  └─ [Combo 1~N] 消除連鎖：
      │     ├─ parseData()         → 解析消除位置
      │     ├─ fadeInBlack()       → 壓黑背景
      │     ├─ score.showMultipleValue() → 顯示贏分×乘倍
      │     ├─ totalWin 累加
      │     ├─ setClearEffect()    → 播放消除特效
      │     ├─ split()             → 圖標分裂動畫
      │     ├─ showCardBack()      → 金色牌顯示牌背
      │     ├─ fadeOutBlack()      → 恢復背景
      │     ├─ drop()              → 新圖標從上方掉落
      │     ├─ showDragonEffect()  → 龍珠特效
      │     ├─ jokerFeature()      → 翻牌（大小鬼）
      │     │  ├─ jokerFlop()      → 金色牌翻成 Joker
      │     │  └─ sprayBigJoker()  → 大鬼散播到其他位置
      │     └─ moveDragonBall()    → 龍珠前進
      │
      └─ 更新餘額 / 清除訊息
         │
         └─ S202_Combo.playEnding() → Feature 結束 → 回到主流程
```

## 五、FreeGame 流程

### 進入

```
AfterShowAward 階段
│
├─ specialGameAgent 檢測到 sgState == INIT
├─ 播放進入動畫/訊息
│
└─ S202_FreeGame.enterSpecialGameOpening()
   ├─ isExecuting = true
   ├─ registerEvent(true)    → 監聽 wheelCtrl.eventFinished
   ├─ sendFeverCommand(null) → 請求第一手 FG 資料
   └─ Transition()
      ├─ 切換場景（MainGame BG → FreeGame BG）
      ├─ 播放轉場 Spine 動畫
      ├─ 初始化龍珠
      └─ eventActiveFreeGameBar → 啟用 FG 次數條
```

### 每手執行循環

```
┌──────────────────────────────────────────────────────────┐
│  Server 回傳 FeverData                                    │
│  └─ S202_FreeGame.getRequest(jsonData)                   │
│     ├─ data.Parse(sg_map)      → 解析盤面/次數            │
│     └─ receiveProcessData()                              │
│        ├─ sgMap = jsonData['sg_map']                      │
│        ├─ winType / thisWin / totalWin 賦值               │
│        ├─ lastTotalWin 記錄                               │
│        ├─ awardController.initCustomized()               │
│        ├─ wheelCtrl.spinRequest() → 設定停輪資料           │
│        └─ wheelCtrl.stopAll()     → 直接停輪              │
└─────────────────────────┬────────────────────────────────┘
                          │ 停輪完成 → eventFinished
                          ▼
┌──────────────────────────────────────────────────────────┐
│  onAllWheelsSpinComplete()                               │
│  ├─ 有 retrigger → Retrigger()（追加次數）                │
│  └─ 無 → prepareShowAward()                              │
│     ├─ 檢查 hit_max_win                                  │
│     │  ├─ true → showMaxWin() → finishedToShowAward      │
│     │  └─ false → finishedToShowAward()                  │
│     └─ → Feature/Award 流程（同主遊戲）                    │
└─────────────────────────┬────────────────────────────────┘
                          │ 報獎完成
                          ▼
┌──────────────────────────────────────────────────────────┐
│  doAfterShowAward()                                      │
│  ├─ sg_state != END → finishedDoAfterProcess()           │
│  │                     └─ doProcess()                    │
│  │                        ├─ 更新 FG 次數顯示             │
│  │                        ├─ sendFeverCommand()          │
│  │                        └─ wheelsManager.spin()        │
│  │                           → 等待下一手 Server 回傳      │
│  │                                                       │
│  └─ sg_state == END → Leave()                            │
└─────────────────────────┬────────────────────────────────┘
                          │
                          ▼
┌──────────────────────────────────────────────────────────┐
│  Leave()                                                 │
│  ├─ registerEvent(false)     → 移除事件監聽               │
│  ├─ Status = MainGame                                    │
│  ├─ 恢復主遊戲盤面（mainReels）                            │
│  ├─ BackToMain()             → 場景切回主遊戲              │
│  ├─ 播放主遊戲 BGM                                       │
│  ├─ sceneManager.Leave(totalWin) → 顯示總贏分面板         │
│  └─ finishSpecialGame()      → 通知框架 SG 結束           │
│     └─ → MainGameHost.onBackToMainGameMode()             │
│        └─ 回到主循環 ProcessFinish                        │
└──────────────────────────────────────────────────────────┘
```

## 六、斷線恢復（Recovery）流程

```
GameInit 完成 → MachineHost 收到 startGameData
│
├─ startGameData 中 sgState != NO_SG → 需要恢復
│
└─ MainGameHost.handleStartGameData()
   ├─ hasRecovery = true
   ├─ specialGameAgent.setRecovery(gameStatusData)
   │  └─ S202_FreeGame.recovery(jsonData)
   │     ├─ Status = FreeGame
   │     ├─ registerEvent(true)
   │     ├─ data.Parse(sg_map)
   │     ├─ 恢復 FG 畫面（背景/龍珠/盤面）
   │     ├─ dropManager.totalWin = totalWin
   │     ├─ playFreeGameBGM()
   │     └─ finishRecovery()
   │
   └─ MainGameHost 從 ShowAward 狀態開始跑
      → 完成後進入正常 FG 循環
```

## 七、關鍵事件對照表

| 事件名稱 | 觸發時機 | 發送者 | 接收者 |
|---------|---------|--------|--------|
| `eventSpin` | 玩家點 Spin | UI | MainGameHost + MachineHost |
| `eventReadyToSpin` | 準備好接受操作 | MainGameHost | UI（解鎖按鈕）|
| `eventWheelStop` | 所有輪停止 | MainGameHost | UI / Feature |
| `eventProcessFinish` | 一回合結束 | MainGameHost | UI / 活動模組 |
| `receiveSpinData` | 收到 Spin 結果 | MachineHost | 各監聽者 |
| `sendNextFeverCmd` | FG 要下一手 | S202_FreeGame | MachineHost |
| `receiveFeverData` | 收到 FG 結果 | MachineHost | S202_FreeGame |
| `eventActiveFreeGameBar` | FG 進/出 | S202_FreeGame | UI |
| `eventCheckMaxWin` | 檢查封頂 | MainGameHost | MaxWinCtrl |
| `eventClickStop` | 快停 | UI | WheelsBlockManager |
